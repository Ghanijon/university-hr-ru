# 9. Дизайн: UI-kit и вайрфреймы

В курсе дизайн делается в Figma. Figma-файл нельзя положить в Git в удобном для чтения виде,
поэтому в репозитории хранятся:

- этот документ — **UI-kit**: цвета, шрифты, отступы, компоненты (то, что в Figma оформляется
  как Styles и Components);
- **вайрфреймы** (wireframes) — статичные HTML-страницы в оттенках серого в папке `wireframes/`.
  Откройте `wireframes/index.html` в браузере.

Студенту: сделайте то же самое в Figma — фреймы 1440 × 900 (desktop) и 390 × 844 (mobile),
стили цветов и текста, компоненты с вариантами (Variants) и Auto Layout. Ссылку на Figma-файл
положите в README своего проекта.

## 9.1. User flow (основные сценарии)

```
Сотрудник:     /login → / (dashboard) → «Подать заявку» → /leaves/create → /leaves (статус «Ожидает»)
Зав. кафедрой: /login → / (бейдж «2 заявки ждут») → /leaves?status=pending → «Согласовать»
Специалист ОК: /login → / → /leaves?status=head_approved → «Утвердить»
               /employees → поиск «Рах…» → карточка /employees/2 → «Редактировать» → сохранить
Руководство:   /login → /reports/staff → «Печать»
```

Правило трёх кликов (NFR-06): любая типовая операция доступна не более чем за 3 перехода от главной.

## 9.2. Сетка и адаптивность

| Точка (Bootstrap) | Ширина | Макет |
|---|---|---|
| xs | < 576 px | одна колонка, меню скрыто в «гамбургер», таблица → карточки |
| md | ≥ 768 px | таблицы, формы в 2 колонки |
| lg | ≥ 992 px | горизонтальное меню, карточка сотрудника: фото слева, данные справа |
| xl | ≥ 1200 px | контейнер 1140 px, dashboard — 4 карточки в ряд |

Контейнер — `.container` (максимум 1140/1320 px), сетка — 12 колонок, промежуток (gutter) 24 px.

## 9.3. Цвета

Основной цвет — «институтский синий». Цвета задаются CSS-переменными в `public/assets/css/app.css`
и переопределяют переменные Bootstrap.

| Токен | HEX | Назначение | Контраст с белым |
|---|---|---|---|
| `--hr-primary` | `#1D4F91` | Кнопки, ссылки, активный пункт меню | 8.1 : 1 |
| `--hr-primary-dark` | `#163C6E` | Наведение на кнопку | 11.0 : 1 |
| `--hr-primary-light` | `#E8EFF8` | Фон выделенной строки, бейдж роли | — |
| `--hr-bg` | `#F4F6F9` | Фон страницы | — |
| `--hr-surface` | `#FFFFFF` | Карточки, таблицы, формы | — |
| `--hr-border` | `#DDE2E8` | Рамки, разделители | — |
| `--hr-text` | `#1F2733` | Основной текст | 15.0 : 1 |
| `--hr-muted` | `#5D6B7E` | Подписи, вторичный текст | 5.4 : 1 |
| `--hr-success` | `#1E7B4F` | «Утверждено», «Работает» | 5.2 : 1 |
| `--hr-warning` | `#9A6100` | «Ожидает» | 5.1 : 1 |
| `--hr-info` | `#1F6FA8` | «Согласовано зав. кафедрой», «В отпуске» | 5.4 : 1 |
| `--hr-danger` | `#B42318` | «Отклонено», «Уволен», удаление, ошибки | 6.6 : 1 |

Контраст проверен по WCAG 2.1 (уровень AA требует 4.5 : 1 для обычного текста).
Статусы никогда не передаются **только** цветом — у бейджа всегда есть текст.

| H1 | 28 / 36 px | 600 | Заголовок страницы |
| H2 | 22 / 30 px | 600 | Заголовок раздела, ФИО в карточке |
| H3 | 18 / 26 px | 600 | Заголовок карточки (card-header) |
| Body | 15 / 24 px | 400 | Основной текст, таблицы, формы |
| Small | 13 / 20 px | 400 | Подписи, подсказки под полем, бейджи |

## 9.5. Отступы и скругления

Шкала отступов кратна 4: **4, 8, 12, 16, 24, 32, 48 px** (в Bootstrap — классы `p-1`…`p-5`, `gap-3` и т. д.).

| Элемент | Значение |
|---|---|
| Внутренний отступ карточки | 24 px |
| Расстояние между полями формы | 16 px |
| Расстояние между секциями | 32 px |
| Высота поля ввода и кнопки | 40 px |
| Скругление (`--hr-radius`) | 8 px; бейджи — 999 px (пилюля) |
| Тень карточки | `0 1px 2px rgba(16, 24, 40, .06)` |

## 9.6. Компоненты

| Компонент | Варианты (Variants) | Bootstrap-класс | Примечание |
|---|---|---|---|
| Кнопка | primary / outline-secondary / danger / success; размер md, sm | `.btn .btn-primary` | Иконка слева необязательна; минимальная зона нажатия 40 × 40 px |
| Поле ввода | обычное / фокус / ошибка / отключено | `.form-control`, `.is-invalid` | Подпись над полем, ошибка под полем красным |
| Выпадающий список | обычный / ошибка | `.form-select` | Кафедра, должность, статус |
| Бейдж статуса заявки | pending «Ожидает», head_approved «Согласовано зав. кафедрой», approved «Утверждено», rejected «Отклонено» | `.badge .status-*` | Цвета — раздел 9.3 |
| Бейдж статуса сотрудника | active «Работает», on_leave «В отпуске», dismissed «Уволен» | `.badge .status-*` | |
| Карточка | stat (число + подпись) / content | `.card` | Dashboard, карточка сотрудника |
| Таблица | с наведением, компактная | `.table .table-hover` | На мобильных — горизонтальная прокрутка внутри `.table-responsive` |
| Пагинация | — | `.pagination` | «‹ 1 2 3 ›», текущая страница выделена |
| Уведомление (flash) | success / danger / warning | `.alert` | Показывается один раз после редиректа |
| Модальное окно | подтверждение удаления | `.modal#confirm-delete-modal` | «Удалить сотрудника Рахимов Ф.? Действие нельзя отменить» |
| Аватар | фото / инициалы | `.avatar` | 96 px в карточке, 32 px в списке; при отсутствии фото — инициалы на сером фоне |
| Навигация | desktop / mobile (гамбургер) | `.navbar .navbar-expand-lg` | Пункты зависят от роли |
| Живой поиск | таблица обновляется при вводе | `#employee-search`, `#employees-tbody` | Запрос через 300 мс после паузы ввода; итог — в `#employee-search-status` (`aria-live`) |

## 9.7. Доступность (accessibility)

- Все поля формы связаны с подписями (`<label for>`), ошибки привязаны через `aria-describedby`.
- Порядок табуляции совпадает с визуальным порядком; фокус виден (обводка 3 px).
- Изображения имеют `alt` («Фото: Рахимов Фарход»).
- Язык страницы указан: `<html lang="ru">`.
- Интерактивные элементы — `<button>` и `<a>`, а не `<div onclick>`.
- Проверка: Lighthouse → Accessibility не ниже 90 (день 15).

## 9.8. Вайрфреймы

| Экран | Файл | Маршрут |
|---|---|---|
| Вход | `wireframes/login.html` | `/login` |
| Главная (dashboard) | `wireframes/dashboard.html` | `/` |
| Список сотрудников | `wireframes/employees.html` | `/employees` |
| Карточка сотрудника | `wireframes/employee.html` | `/employees/{id}` |
| Форма сотрудника | `wireframes/employee-form.html` | `/employees/create`, `/employees/{id}/edit` |
| Заявки на отпуск | `wireframes/leaves.html` | `/leaves` |
| Новая заявка | `wireframes/leave-form.html` | `/leaves/create` |
| Отчёт «штат по кафедрам» | `wireframes/report.html` | `/reports/staff` |

Вайрфрейм — это **схема** без цвета и картинок: серые блоки показывают расположение элементов,
а не их оформление. Цвета и шрифты из разделов 9.3–9.4 появляются только на этапе макета (mockup)
и вёрстки (день 10).
