# 2. Сравнительная матрица аналогов

Цель документа — понять, какие готовые решения уже есть, чем они хороши и почему вузу всё-таки
нужна собственная небольшая система. Результат анализа — список функций, которые мы берём в свой проект,
и список того, что сознательно не делаем.

## 2.1. Как искать аналоги

1. Поисковые запросы: «HR system university», «кадровый учёт вуза», «HRMS open source», «leave management system».
2. Каталоги ПО: G2, Capterra (обзоры и рейтинги), GitHub (открытые проекты).
3. Опрос: что используют соседние вузы и предприятия Согдийской области.
4. Для каждого кандидата — демо-версия или видеообзор, документация, страница цен.

Отобрано пять аналогов разных классов:

| № | Система | Класс | Кратко |
|---|---|---|---|
| A1 | 1С:Зарплата и управление персоналом (1С:ЗУП) | Коробочная, on-premise | Стандарт кадрового и зарплатного учёта в странах СНГ |
| A2 | BambooHR | SaaS (облако) | Популярная HR-платформа для малого и среднего бизнеса в США |
| A3 | Odoo HR (модули Employees, Time Off) | ERP, open core | Модульная ERP с открытым ядром, можно развернуть у себя |
| A4 | OrangeHRM Starter | Open source | Бесплатная HRM-система на PHP + MySQL |
| A5 | Frappe HR (бывш. ERPNext HRMS) | Open source | HRMS на Python (фреймворк Frappe) |

## 2.2. Критерии сравнения

Шкала оценки: **0** — нет; **1** — частично / через доработку; **2** — есть «из коробки».

| Код | Критерий | Почему важен для вуза |
|---|---|---|
| K1 | Карточка сотрудника и справочники (подразделения, должности) | Основа кадрового учёта |
| K2 | Процесс отпуска с многоуровневым согласованием | Главная боль отдела кадров |
| K3 | Учёт особенностей вуза (кафедры, учёные степени, ППС) | В типовых системах этого обычно нет |
| K4 | Кадровые приказы | Обязательный документооборот |
| K5 | Поиск, фильтры, отчёты | Ответы руководству «за минуту» |
| K6 | UX: простота интерфейса, порог входа | Пользователи — не ИТ-специалисты |
| K7 | Русская локализация (интерфейс, кириллица в данных, местные форматы дат и телефонов) | Пользователи — сотрудники вуза в Худжанде |
| K8 | Мобильность (адаптивный веб или приложение) | Заведующий согласует с телефона |
| K9 | Стоимость владения | Бюджет вуза ограничен |
| K10 | Скорость работы и требования к серверу | Сервер института скромный |

Пояснения к оценкам:

- **1С:ЗУП** — самый полный по кадровому документообороту (унифицированные формы, приказы, расчёт отпускных),
  но нормативная база ориентирована на РФ, интерфейс сложный, требуется обученный специалист
  и платное сопровождение. Русский — да, но локализация под РФ (оценка 1).
- **BambooHR** — очень удобный интерфейс и мобильное приложение, гибкие процессы отпусков (Time Off),
  но только английский интерфейс, хранение данных в облаке за рубежом, цена — по запросу,
  оплата за каждого сотрудника ежемесячно. Приказов в понимании СНГ нет.
- **Odoo HR** — модули Employees и Time Off закрывают карточку и отпуска с двухуровневым согласованием.
  Есть русская локализация. Community-версия бесплатна, но часть функций только в платной Enterprise.
  Для вуза нужна доработка (кафедры = departments, учёные степени — дополнительные поля).
- **OrangeHRM Starter** — бесплатная open source система на том же стеке, что и наш курс (PHP + MySQL).
  Хороший пример для изучения кода. Модуль Leave есть, отчёты в бесплатной версии скромные.
- **Frappe HR** — богатая функциональность (Leave Application с workflow, отчёты, мобильное приложение),
  но требует Python-стека, Redis, MariaDB, Node.js — тяжело сопровождать силами одного администратора.

> Важно: цены и состав функций меняются. Перед защитой проверьте актуальные данные на официальных сайтах
> и укажите дату проверки. Сравнение составлено по документации и демо-версиям, доступным осенью 2026 г.

## 2.4. Сравнение по стоимости (ориентировочно)

| Система | Модель лицензирования | Что ещё нужно |
|---|---|---|
| 1С:ЗУП | Разовая лицензия + клиентские лицензии + договор сопровождения | Платформа 1С, Windows-сервер, обученный специалист |
| BambooHR | Подписка, цена за сотрудника в месяц, по запросу | Интернет, согласие на хранение ПДн за рубежом |
| Odoo HR | Community — бесплатно; Enterprise — подписка за пользователя | Сервер с PostgreSQL, Python |
| OrangeHRM Starter | Бесплатно (GPL) | Сервер PHP + MySQL |
| Frappe HR | Бесплатно (GPL) | Сервер Python + MariaDB + Redis + Node.js |
| university-hr | Собственная разработка | VDS: Nginx + PHP-FPM + MySQL (самый дешёвый тариф достаточен) |

## 2.5. Выводы

1. Ни один аналог не учитывает специфику местного вуза «из коробки»: кафедры с заведующими как
   первым уровнем согласования, учёные степени (кандидат, доктор наук, PhD), отчёт «штат по кафедрам».
2. **Берём в свой проект** лучшее из аналогов:
   - из BambooHR — простой интерфейс и мобильную вёрстку, карточку сотрудника с фото;
   - из Odoo и Frappe HR — двухуровневое согласование отпуска со статусами;
   - из 1С:ЗУП — кадровые приказы с номером и типом;
   - из OrangeHRM — стек PHP + MySQL, который легко развернуть на дешёвом VDS.
3. **Сознательно не делаем** (выходит за рамки MVP): расчёт зарплаты и отпускных, табель учёта рабочего
   времени, интеграцию с бухгалтерией, электронную подпись приказов.
4. Собственная система оправдана: стоимость владения минимальна, данные хранятся на сервере института,
   интерфейс полностью на русском, данные хранятся в utf8mb4.

## 2.6. Задание студенту

Составьте такую же матрицу для своей темы: 3–5 аналогов × 8–10 критериев, шкала 0/1/2,
колонка «моя система», 4–5 выводов «что берём / что не делаем». Для темы «Заказ такси» аналоги —
Yandex Go, Maxim, местные службы такси; для каталога «Объявления» — Somon.tj, OLX, Avito.
